# Quality Gate

The plan or implementation is not done until these checks are true.

## Strategy

- One offer.
- One audience.
- One primary CTA.
- Clear conversion goal.
- Objections handled before final CTA.
- Proof is close to claims.
- Every major change has a source/reason/task/QA chain.

## Design

- Design Read is explicit.
- Dials are explicit: DESIGN_VARIANCE, MOTION_INTENSITY, VISUAL_DENSITY.
- Responsive viewport map exists before implementation handoff.
- First viewport is planned for mobile, desktop and wide.
- One visual theme across the page.
- One accent system across the page.
- One radius system across the page.
- Hero fits first viewport.
- CTA visible without scroll on desktop.
- Mobile CTA, headline and hero subject fit intentionally.
- Wide desktop composition is not stretched or empty.
- Navigation is one line on desktop and under 80px height.
- No default three-card feature row unless brief truly needs it.
- No random AI-purple/dark-mesh default.
- No section layout repeats more than needed.

## Copy

- Every visible string was reread.
- Every visible claim/proof item has a claim verdict.
- No fake metrics.
- No fake customers/testimonials/logos.
- No generated or mock UI is presented as real proof.
- CTA label is consistent for the same intent.
- Subheads are specific and short.
- FAQ answers real objections.

## Motion

- Motion reference map exists before recipe/storyboard.
- Accepted motion references include borrow, transform and do-not-copy boundaries.
- Motion safety source map was read before accepting motion recipes.
- Every accepted motion row has a motion safety verdict: safe, needs-simplification, static-fallback-only or reject.
- Motion Primitives selection exists before any Motion Primitives install or adaptation.
- Magic UI selection exists before any Magic UI install or adaptation.
- Aceternity UI selection exists before any Aceternity UI install, copy or adaptation.
- Tailark section selection exists before any Tailark install, copy or adaptation.
- shadcnblocks selection exists before any shadcnblocks install, copy or adaptation.
- Micro component selection exists before any Kibo UI, Origin/Coss UI or similar micro-component install, copy or adaptation.
- React Bits selection exists before any React Bits install, copy or adaptation.
- PaceKit GSAP selection exists before any PaceKit GSAP install, copy or adaptation.
- Cult UI selection exists before any Cult UI install, copy or adaptation.
- ReUI selection exists before any ReUI install, copy or adaptation.
- 21st.dev selection exists before any 21st.dev install, copy or adaptation.
- Kokonut UI selection exists before any Kokonut UI install, copy or adaptation.
- MVPBlocks selection exists before any MVPBlocks install, copy or adaptation.
- SmoothUI selection exists before any SmoothUI install, copy or adaptation.
- HextaUI selection exists before any HextaUI install, copy or adaptation.
- Skiper UI selection exists before any Skiper UI install, copy, reference or adaptation.
- Eldora UI selection exists before any Eldora UI install, copy, reference or adaptation.
- Blocks.so selection exists before any Blocks.so install, copy, reference or adaptation.
- Intent UI selection exists before any Intent UI install, copy, reference or adaptation.
- Every animation has a purpose.
- Motion claimed is motion shown.
- Reduced-motion fallback exists.
- No `window.addEventListener("scroll")` for scroll animation.
- GSAP only for actual pin/scrub choreography.
- Motion does not hide content or shift layout.
- Motion does not threaten LCP, INP or CLS without a written mitigation.

## Assets

- Hero has a real visual asset or a planned generated asset.
- Images have stable dimensions.
- Asset crop rules exist for mobile and wide when visual assets matter.
- Logos are real SVGs or clearly generated marks.
- No div-based fake screenshots unless it is a real live component preview.
- 3D/WebGL is used only if it carries meaning.

## Accessibility And Performance

- Text contrast passes WCAG AA.
- Buttons have hover, focus, active states.
- Forms have labels, helper/error text.
- Mobile layouts are explicit.
- LCP asset is optimized.
- CLS space is reserved.
- Heavy components are lazy-loaded if below the fold.
