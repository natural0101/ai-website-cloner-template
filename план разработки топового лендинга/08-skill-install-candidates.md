## Reference Only For Now

### github/awesome-copilot premium frontend UI

Decision: reference only.

Reason: useful premium/polish mindset, but the skill may encourage over-motion and UI gimmicks that conflict with our taste and performance gates.

### Motion AI Kit

Decision: reference only unless user buys/uses Motion+.

Reason: official Motion docs mention AI Kit availability for Codex, but Motion+ is a paid product. We should not assume access.

### Hover.dev

Decision: reference-only/gated copy source.

Reason: useful interaction/component inspiration with a live license page and free/pro split, but there is no verified shadcn/jsrepo registry. Use exact free components or licensed Pro access only, then record access, license, files, dependency impact, adaptation, fallback, mobile and QA in the relevant selection file.

### SaaSFrame, Mobbin, Page Flows, Landingfolio, Recent/Godly, Siteinspire, Minimal Gallery, Refero, HTTPSTER

Decision: reference only.

Reason: these are research/benchmark sources, not installable runtime libraries. Use `52-reference-gallery-source-map.md` and `landing-reference-source-catalog` to choose the correct lane, record access status and promote only section-useful references.

## Rejected Pattern

Any skill or component pack that says "make it premium" by defaulting to:

- custom cursor;
- blocking preloaders;
- full-page scroll hijack;
- endless glows;
- every section animated;
- fake dashboard screenshots;
- generic AI-purple gradients.

These can work only if a brief specifically supports them and quality gates pass.
