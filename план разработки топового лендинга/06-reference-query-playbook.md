# Reference Query Playbook

Use this when a dossier arrives and the agent needs better references.

Before searching, read `52-reference-gallery-source-map.md` and choose a source lane. Do not use all galleries at once.

## Source Routing

| Lane | Start with | Notes |
| --- | --- | --- |
| Direct/domain landing | SaaS Landing Page, SaaSFrame, Landingfolio, Lapa Ninja, Land-book, direct competitors | Land-book, Lapa, Saaspo may require browser/manual access. Record access status. |
| Product flow | Mobbin, Pageflows | Use for onboarding, signup, checkout, app screenshots and workflow. Premium/account-gated material is reference-only. |
| Visual language | Recent/Godly, Siteinspire, Minimal Gallery, MaxiBestOf, Refero, HTTPSTER, Dark Mode Design | Use for mood, typography, composition and art direction. Reject if no section use. |
| Motion/interaction | Awwwards, Codrops, Motion Examples, Motion docs | Motion must map to hierarchy, storytelling, feedback or state transition. |
| CRO/UX evidence | Baymard, NN/g | Use to justify form, checkout, trust, pricing, heuristic or usability decisions. |
| Header/navigation | Navbar Gallery, direct competitors, shadcnblocks/Tailark examples | Preserve current IA and CTA unless the source dossier allows changes. |

## Reference Types To Collect

Minimum per plan:

- 3 direct/domain references.
- 2 adjacent or analogous references with a clear closeness reason.
- 3 aesthetic references.
- 2 motion/component references.
- 1 motion implementation source when an animation will become a recipe.
- 1 performance/accessibility source if heavy animation or media is planned.
- 1 anti-reference when the category is crowded or generic.

## How To Judge A Reference

For every reference, answer:

- Why is it close enough: product, audience, CTA, trust model, workflow, asset type, emotion or interaction?
- What job does this reference do better?
- Which section does it inform?
- What would be wrong to copy?
- What is reusable as a principle?
- What is the risk: license, over-motion, brand mismatch, low accessibility, heavy media?

## Good Borrowing

- Borrow layout rhythm.
- Borrow interaction logic.
- Borrow asset composition.
- Borrow copy structure.
- Borrow hierarchy.

## Bad Copying

- Copying exact visual identity.
- Copying premium/pro code without license.
- Copying a motion effect without a user-facing purpose.
- Copying a competitor's claims, logos, or proof.
- Copying page structure when the offer differs.
