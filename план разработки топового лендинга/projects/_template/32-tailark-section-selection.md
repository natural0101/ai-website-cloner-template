## License And Adaptation Notes

- Public Tailark repo is MIT, but still record the exact source and install URL.
- Public item URLs use `https://tailark.com/r/<name>.json`; root `/registry.json` is not a valid source.
- Old public sitemap preview URLs can be stale; confirm preview URLs return 200.
- Treat Tailark Pro as reference-only unless API-key access and license are explicit.
- Replace demo copy, logos, screenshots, claims, icons and colors with project evidence and style tile rules.
- Record dependency changes in `08-component-and-asset-plan.md`.
- Add screenshot QA, mobile QA, contrast QA and reduced-motion checks before handoff.
