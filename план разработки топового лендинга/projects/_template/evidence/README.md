# Evidence Pack

Use this folder to keep proof for every design decision.

## Folders

- `screenshots/` - current page, mobile crops, reference screenshots, final QA screenshots.
- `references/` - downloaded notes or summaries for external references.
- `assets/` - asset prompts, generated asset notes, source URLs, GLB/render notes.
- `notes/` - decision logs and review notes.

## Required Manifests

- `reference-manifest.md`
- `screenshot-manifest.md`
- `asset-manifest.md`
- `decision-log.md`

Do not treat a plan as implementation-ready if there are no screenshots, no reference URLs, and no decision evidence.
