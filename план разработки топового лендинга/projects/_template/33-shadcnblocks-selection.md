## License And Adaptation Notes

- Public registry examples use `https://www.shadcnblocks.com/r/<id>.json`; root `/registry.json` is not valid.
- Free GitHub repo uses MIT plus Commons Clause. Do not redistribute components as a component kit, marketplace item, builder, AI generator, or competing product.
- Pro/Premium items require explicit access and license approval; without it mark `reference-only`.
- Replace demo copy, images, logos, icons, metrics and claims with project evidence.
- Adapt spacing, palette, typography, radius, surface treatment, icons and motion to the project style tile.
- Record dependency changes in `08-component-and-asset-plan.md`.
- Add screenshot QA, mobile QA, contrast QA and reduced-motion checks before handoff.
