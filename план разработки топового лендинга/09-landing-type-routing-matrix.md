# Landing Type Routing Matrix

Use this matrix after reading `landing-source-dossier.md`.

## SaaS / B2B Product

- Primary skills: `landing-page-high-conversion`, `landing-copy-offer-audit`, `landing-reference-research`, `landing-visual-benchmark`.
- References: SaaS Landing Page, Saaspo, Land-book, direct competitors.
- Components: shadcn/ui, Animate UI, Motion Primitives, shadcnblocks for structure if customized, React Bits only for one earned text/background moment.
- Assets: real product screenshots, dashboard crops, workflow diagrams, customer logos.
- Motion: restrained reveals, tabs/accordion, product state transitions.
- Avoid: fake dashboards, fake metrics, generic three-card feature row.

## AI / Developer Tool

- Primary skills: `design-taste-frontend`, `landing-motion-storyboard`, `motion-component-source-map`.
- References: direct competitors, Awwwards only for interaction, Motion docs, Codrops for one strong pattern.
- Components: Animate UI, Magic UI, Motion Primitives, React Bits, PaceKit GSAP only for justified choreography, Cult UI for exact product surfaces/widgets, terminal/code components only if real.
- Assets: real UI screenshots, code examples, short demo clips, 3D only if it explains the model/system.
- Motion: text reveal, command state transition, scroll reveal, one signature hero animation; GSAP only when the sequence earns it.
- Avoid: AI-purple glow by default, fake terminal, fake eval numbers.

## Consumer App / Mobile App

- Primary skills: `landing-asset-art-direction`, `landing-visual-benchmark`, `imagegen-frontend-mobile`.
- References: Mobbin, Page Flows, app store pages, product-led landing pages.
- Components: app mockup frame, carousel, comparison blocks, FAQ, Kibo/Origin/ReUI primitives for forms and product UI proof.
- Assets: real mobile screenshots, onboarding screens, short video/GIF, lifestyle image if relevant.
- Motion: phone mockup entrance, screen carousel, tactile CTA.
- Avoid: blank phone frames, generic emoji-led feature cards.

## E-commerce / Premium Product

- Primary skills: `landing-copy-offer-audit`, `landing-asset-art-direction`, `design-taste-frontend`.
- References: Land-book, Godly/Recent, direct product category pages.
- Components: product hero, specs, reviews, comparison, FAQ, purchase CTA, Tailark/shadcnblocks for structure only.
- Assets: product photography, detail crops, material shots, generated product renders if needed.
- Motion: product reveal, hover zoom, gallery interaction, subtle sticky buy bar if useful.
- Avoid: beige/brass default palette unless brand demands it, long spec tables, fake reviews.

## Local Service / Booking

- Primary skills: `landing-page-high-conversion`, `landing-copy-offer-audit`, `ui-audit`.
- References: direct local competitors, high-performing booking pages, Google Business-style proof.
- Components: booking CTA, service cards, map/contact, testimonial proof, FAQ.
- Assets: real location/team photos, before/after images, trust badges if real.
- Motion: minimal. Focus on clarity and speed.
- Avoid: experimental scroll effects, unclear phone/booking CTA.

## Agency / Creative Studio

- Primary skills: `design-taste-frontend`, `landing-reference-research`, `landing-motion-storyboard`, `landing-visual-benchmark`.
- References: Awwwards, Godly/Recent, Codrops, portfolio references.
- Components: project index, case-study cards, kinetic type, selected work, contact CTA.
- Assets: real project images, video snippets, typography-first compositions.
- Motion: one strong scroll/storytelling pattern, tasteful hover previews.
- Avoid: decorative locale/time strips, custom cursor by default, repeated manifesto labels.

## 3D / WebGL Hero Landing

- Primary skills: `landing-asset-art-direction`, `landing-motion-storyboard`, `webgl-3d-object`, `three-js-animation`, Blender workbench rules.
- References: Awwwards, Codrops, Three.js examples, product category references.
- Components: full-bleed hero scene, static fallback, section-linked visual states.
- Assets: GLB, compressed textures, poster render, mobile fallback.
- Motion: idle rotation, camera reveal, scroll-linked state only if meaningful.
- Avoid: blank canvas, unreadable object, heavy 3D below vague copy.

## Waitlist / Launch Page

- Primary skills: `landing-page-high-conversion`, `landing-copy-offer-audit`, `landing-visual-benchmark`.
- References: launch pages, Product Hunt launches, direct competitors.
- Components: short hero, proof/who it is for, waitlist form, FAQ, privacy note.
- Assets: one strong hero visual or product preview.
- Motion: small entrance and form feedback.
- Avoid: too many sections, fake scarcity counters, beta labels unless true.

## Clone / Redesign Existing Page

- Primary skills: `clone-website`, `design-taste-frontend`, `landing-visual-benchmark`, `landing-upgrade-orchestrator`.
- References: original page first, then competitors.
- Components: preserve IA, upgrade typography/spacing/assets.
- Assets: reuse real assets where allowed.
- Motion: add only after preserving structure and SEO.
- Avoid: changing route slugs, nav labels, form fields, legal copy, analytics labels without approval.
