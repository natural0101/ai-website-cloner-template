# Данные, которые могут понадобиться от пользователя

## Обязательно сейчас

Ничего. Каталог, транскрипты, storyboard-доказательства, topic-level решения,
Blender 5.1 capability probe и текущая ветка кота доступны локально.

## Только если нужна точная атрибуция трёх источников

Для `6GLHDS2vRd0`, `u9n5PJZMzLU` и `kvYqHYgHXSI` сохранённых кадров и речи
недостаточно, чтобы честно назвать точный оператор, аддон или параметры.
Подойдёт любой один из вариантов:

- исходный проект автора;
- непрерывная экранная запись с читаемым интерфейсом;
- исправленный транскрипт/озвучка нужного фрагмента;
- ссылка автора на использованный аддон или отдельный технический разбор.

Без этих данных источники остаются `showcase_only`/`not_applicable`; техника
по внешнему виду результата не выдумывается.

## Перед установкой конкретного аддона

Нужно отдельное решение пользователя о самом аддоне. После него проверяются
официальный источник, лицензия/цена, Blender 5.1, разрешения, сеть и isolated
runtime test. Ни один из 301 каталогизированного аддона не установлен
автоматически.
