# Landing Upgrade Orchestrator

Use this skill when the user wants to improve a simple landing page into a top-tier landing page, especially when a `landing-source-dossier.md` was produced in another project.

## Workflow

1. Extract the one offer, one audience, one primary CTA.
2. Classify redesign mode: preserve, targeted evolution, or overhaul.
3. Declare Design Read and dials.
4. Build a reference board with direct, aesthetic, and motion references.
5. Define a visual system: type, palette, radius, density, imagery, icon family, theme.
6. Write a section-by-section upgrade plan.
7. Write an animation storyboard with purpose for each motion.
8. Choose component and asset sources with dependency impact.
9. Convert the plan into ordered implementation tasks.
10. Attach quality gates and verification steps.

## Writing Standard

Use visible design rationale, not hidden chain-of-thought. The plan should say:

- what the user will see;
- why it helps conversion or comprehension;
- what source inspired it;
- how it will be implemented;
- how it will be checked.

Bad: "Make hero more premium."

Good: "Hero becomes an asymmetric split: left side has a 7-word outcome headline and one CTA, right side has a real product/3D visual. The visual enters with a 12px y-offset fade and slow rotation only after LCP. Purpose: hierarchy and product tangibility. Reduced motion: static image."

## Completion Bar

The plan is incomplete if it lacks:

- concrete references;
- section-by-section storyboard;
- animation storyboard;
- component source choices;
- asset plan;
- implementation order;
- QA checklist.
