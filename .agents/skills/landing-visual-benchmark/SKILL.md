# Landing Visual Benchmark

Use this skill to decide whether the page actually looks strong. It is not enough to say "better". Compare the page against references and convert gaps into actions.

## Inputs

- Live URL, screenshot, local preview, or `landing-source-dossier.md`.
- Reference board if available.
- Product category and audience.

## Benchmark Sources

Prefer:

- SaaS Landing Page for SaaS sections and page types.
- Saaspo for filtered SaaS inspiration by page, industry, style, assets, and stack.
- Land-book and Lapa Ninja for broader landing examples.
- Godly/Recent for fresh typography, art direction, and visual mood.
- Awwwards and Codrops for motion, WebGL, and interaction references.

## Workflow

1. Capture current state.
   - Desktop screenshot.
   - Mobile screenshot.
   - Hero crop.
   - Full-page screenshot if possible.

2. Score the page from 1 to 5 in these areas:
   - Hero clarity.
   - Visual hierarchy.
   - Typography.
   - Color and theme consistency.
   - Layout rhythm.
   - Asset quality.
   - Motion usefulness.
   - Trust/proof placement.
   - Mobile composition.
   - Accessibility/performance risk.

3. Compare against 3 to 6 references.
   - What does the reference do better?
   - What would be wrong to copy?
   - Which exact section should borrow the pattern?

4. Convert gaps into actions.
   - Immediate fix: small change with high impact.
   - Structural fix: section recomposition.
   - Asset fix: image, 3D, video, logo, screenshot.
   - Motion fix: add, reduce, or remove animation.

## No-Go Signals

- Hero has no real visual.
- CTA is below the fold on desktop.
- Section layouts repeat without reason.
- All cards look the same.
- Text overlaps or clips.
- Motion exists but does not communicate anything.
- Page looks like a default template after replacing text.
