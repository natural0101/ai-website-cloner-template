Use this skill after reference scoring and before final section decisions.

## Workflow

1. For every accepted reference, write why it is close: audience, offer, product category, workflow, emotion, trust model or asset type.
2. Map each reference to exact sections.
3. Write what to borrow.
4. Write what to transform for this project.
5. Write what not to copy.
6. Convert each borrow into a concrete visible decision.
7. Convert motion references into trigger, visible result, timing, fallback and QA.
8. Convert asset references into asset role, source/path, composition, alt/performance note and risk.
9. Convert anti-references into avoidance rules.
10. Update downstream planning files so references are not left as moodboard-only evidence.

## Rules

- Do not let a beautiful reference define sections where it has weak product or offer fit.
- Do not copy brand identity, exact layout, text, proprietary assets, metrics, testimonials or logos.
- Do not use motion references without reduced-motion fallback.
- Do not use component references as visual direction by themselves.
- Do not leave "premium", "modern", "smooth" or "inspired by" without a visible decision.

## Output Quality

The synthesis is ready when another agent can say:

- which reference inspired which section;
- why that reference is close;
- what is borrowed and transformed;
- what is explicitly not copied;
- what the user will see on screen;
- how motion behaves;
- what asset must exist;
- what mobile and QA risk remains.
