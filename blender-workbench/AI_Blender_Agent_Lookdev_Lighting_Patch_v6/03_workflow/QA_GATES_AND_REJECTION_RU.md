# QA gates и отклонение результата

## Gate A — geometry

PASS только если:

- silhouette читается в clay;
- видимые hard-surface края имеют контролируемый bevel;
- панели имеют толщину;
- нет случайных пересечений;
- предметы стоят на поверхности;
- low-poly гранёность не видна там, где не задумана.

## Gate B — materials

PASS только если:

- painted metal, bare metal, rubber, glass, plastic и ground визуально различимы;
- metallic используется физически осмысленно;
- roughness не одинаковая у всех материалов;
- нет pure-white/pure-black albedo без причины;
- microdetail соответствует масштабу;
- export-unsupported nodes помечены bake-required.

## Gate C — lighting

PASS только если:

- есть понятное направление key;
- fill не делает сцену плоской;
- practical fixtures объясняют локальный свет;
- emitter сохраняет форму и цвет;
- контактные тени читаются;
- окружение не абсолютно чёрное без художественной причины.

## Gate D — exposure

Для текущего кадра стартовая цель:

- full-white clipping < 1% кадра, кроме маленьких намеренных источников;
- any-channel clipping < 5%;
- центральное здание сохраняет текстуру и границы;
- чёрные области не теряют все детали;
- p95 не должен массово упираться в 1.0.

Это не универсальный закон для любого художественного кадра, а критерий исправления именно текущего пересвета.

## Gate E — production render

- Cycles final reference;
- минимум 128 samples или адаптивный эквивалент;
- denoise без потери мелких деталей;
- AgX/exposure сохранены;
- разрешение не ниже целевого;
- PNG/EXR сохранён;
- clay и final доступны для сравнения.

## Gate F — web

- GLB проходит validator;
- материалы и normals не сломаны;
- environment задан в viewer;
- tone mapping задан в viewer;
- screenshot browser приложен;
- размер файла и triangle count соответствуют целевому устройству.

## Автоматическое отклонение

Результат нельзя называть хорошим, если выполняется хотя бы одно:

- более 5% кадра полностью белое из-за ошибки света;
- все материалы выглядят одинаково;
- форма держится только на bloom;
- нет clay render;
- нет checkpoint;
- GLB не проверен в браузере;
- агент изменил geometry, materials и lighting за одну итерацию и не может объяснить улучшение.
