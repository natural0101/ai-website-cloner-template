# Память агента: объёмные фигуры и реконструкция

1. Сначала выбери цель: `FRONT_2_5D`, `TRUE_360` или `HYBRID_HERO`.
2. Одна картинка не содержит достоверной задней геометрии. Не называй придуманную заднюю часть «восстановленной».
3. До материалов зафиксируй resolution, camera type, camera framing и silhouette landmarks.
4. Разложи фигуру на именованные массы: core, palm, fingers, thumb, wrist, cuff и т. п.
5. Создавай крупные формы из ellipsoid/rounded box/tube. Детали — только после правильного силуэта.
6. Части должны перекрываться минимум на 1.5–2 voxel перед Voxel Remesh.
7. Всегда сохраняй `SOURCE` и создавай отдельный `MERGED/OUTPUT`; не разрушай исходники.
8. Контур из картинки — screen‑space constraint, а не готовая 360° геометрия.
9. Для перекрытий составляй явный layer graph: что перед чем находится.
10. После 1–3 правок: render silhouette → compare → исправить одну категорию ошибки.
11. Сначала исправляй camera/translation/scale, затем landmarks, затем volume/profile, потом материал и свет.
12. Для отверстий и negative space требуй точное совпадение их количества до smoothing/remesh.
13. `TRUE_360` проверяй минимум спереди, 3/4, сбоку и сзади; фронтального IoU недостаточно.
14. Не устанавливай AI‑модели внутрь Blender Python. OpenCV и optional AI работают во внешнем venv.
15. Готово только при validation без errors, существующем PNG, сохранённом `.blend` и ненулевом GLB.
