# Термины, которые должен понимать агент

- **Blockout** — грубая сборка крупных объёмов до деталей.
- **Semantic primitives** — части с назначением: ладонь, палец, манжета, корпус, глаз, ручка.
- **Shape from silhouette** — подбор геометрии под наблюдаемый внешний контур.
- **Visual hull** — объём, согласованный с несколькими силуэтами; один силуэт даёт слишком много допустимых объёмов.
- **Single‑view reconstruction** — реконструкция по одному виду; скрытые поверхности неоднозначны.
- **2.5D relief** — объёмный фронтальный рельеф, оптимизированный под одну камеру.
- **View‑conditioned asset** — объект, качество которого гарантируется в оговорённом диапазоне камер.
- **Occlusion/layer graph** — явный порядок перекрытия частей в кадре.
- **Silhouette landmarks** — контрольные точки контура: кончики, впадины, касания, углы.
- **Negative space** — отверстия и просветы между частями.
- **Voxel union/remesh** — перевод пересекающихся частей в единый объёмный mesh.
- **Screen‑space fitting** — правки, измеряемые в пикселях основной камеры.
- **Boundary F1** — насколько близко совпадают границы масок с заданным tolerance.
- **IoU** — площадь пересечения масок, делённая на площадь их объединения.
- **Retopology** — построение более чистой/лёгкой сетки поверх sculpt/high‑poly формы.
