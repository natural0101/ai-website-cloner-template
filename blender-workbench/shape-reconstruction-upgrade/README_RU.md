# Shape Reconstruction Upgrade 1.0

Дополнение для AI Blender Agent Kit, которое учит агента строить **объёмные стилизованные фигуры с нуля** и отдельно решать задачи реконструкции по одному 2D‑референсу.

## Что исправлено

- разделены три разные цели: `FRONT_2_5D`, `TRUE_360`, `HYBRID_HERO`;
- добавлен blockout из семантических частей: ellipsoid, rounded box, Bézier tube;
- добавлены руки из ладони, пальцев, большого пальца, запястья и манжеты;
- добавлено мягкое объединение частей через Voxel Remesh с сохранением исходников;
- добавлен импорт контуров с сохранением отверстий и явным порядком слоёв;
- добавлена фиксированная reference camera;
- добавлен объективный silhouette review: IoU, Dice, boundary F1, отверстия, centroid, bbox;
- добавлены GLB‑проверка, triangle budget и экспорт;
- добавлена отдельная MCP‑обвязка без изменения базового toolkit.

## Главное правило

Одна картинка задаёт наблюдаемый силуэт, цвета и перекрытия, но не определяет единственную правильную заднюю поверхность. Поэтому агент обязан сначала зафиксировать целевой режим, а не обещать одновременно точное фронтальное совпадение и достоверный 360° результат.

## Быстрый маршрут

1. Откройте `00_start/START_HERE_RU.md`.
2. Подключите skill `skills/blender-shape-reconstruction/SKILL.md`.
3. Добавьте каталог `04_blender_tools` в `sys.path` Blender.
4. Для mask/overlay установите отдельный Python‑venv по `05_external_tools/INSTALL_RU.md`.
5. Выполните `06_examples/01_create_hand_sphere_true3d.py`.
6. Посмотрите автоматический отчёт `10_review/QUALITY_REVIEW_RU.md`.

## Структура

| Каталог | Назначение |
|---|---|
| `00_start` | установка, маршрутизация, обязательные настройки |
| `01_agent_memory` | короткая память и prompt для агента |
| `02_reference_intake` | разбор референса, occlusion/layer graph |
| `03_workflows` | TRUE_360, FRONT_2_5D, HYBRID_HERO и QA |
| `04_blender_tools` | исполняемые Blender 5.1 Python‑tools |
| `05_external_tools` | OpenCV contour/mask/overlay инструмент |
| `06_examples` | запускаемые примеры |
| `07_mcp` | manifests и безопасный MCP adapter |
| `08_optional_programs` | необязательная сегментация/depth/image‑to‑3D |
| `09_sources` | первичные источники |
| `10_review` | тесты и независимое ревью пакета |
| `demo` | синтетический референс, маски и реальные результаты тестов |

## Что не загружать постоянно

Не помещайте все файлы в каждый запрос. Постоянно нужны только:

- `01_agent_memory/AGENT_MEMORY_CARD_RU.md`;
- `skills/blender-shape-reconstruction/SKILL.md`.

Остальные документы агент открывает только по маршруту из skill. Это уменьшает конфликт инструкций и расход контекста.
