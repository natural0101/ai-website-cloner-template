# Дерево выбора workflow

## Шаг 1. Что пользователь считает результатом

### Только главный фронтальный вид

Выбрать `FRONT_2_5D`.

Использовать clean masks → contours → explicit layer stack → extrude/bevel. Не тратить время на правдоподобный back view.

### Объект будут вращать

Выбрать `TRUE_360`.

Использовать semantic blockout → multi-view volume review → voxel union/sculpt → topology/GLB. Контур служит ограничением фронтального вида, но не заменяет объём.

### На сайте есть небольшое движение камеры

Выбрать `HYBRID_HERO`.

Сначала добиться front silhouette, затем дать частям ограниченную глубину и проверить диапазон камеры, например ±15°. Не заявлять качество за пределами диапазона.

## Шаг 2. Есть ли чистые маски

- Есть alpha/manual masks: использовать contour pipeline.
- Нет masks, но объект простой: вручную сделать semantic blockout.
- Нет masks, края сложные: optional SAM во внешнем окружении, затем ручная проверка.
- Изображение маленькое и размытое: запросить оригинал; до него работать с явной uncertainty.

## Шаг 3. Есть ли дополнительные виды

- 2+ ортогональных silhouette: можно строить visual-hull‑подобный объём.
- Один вид: скрытая сторона — дизайн/ prior, а не наблюдение.
- Есть видео turntable: извлечь keyframes и calibrate cameras; это отдельная multi-view задача.
