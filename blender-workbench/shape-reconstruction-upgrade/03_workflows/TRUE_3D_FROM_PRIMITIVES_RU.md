# TRUE_360: объём с нуля из семантических примитивов

## Production order

1. Зафиксировать world scale, camera и triangle budget.
2. Создать отдельную коллекцию `SOURCE`.
3. Создать только крупные массы: ellipsoid, rounded box, tube.
4. Проверить front/side/3⁄4 silhouettes без материалов.
5. Подвинуть/масштабировать semantic parts, а не отдельные случайные vertices.
6. Обеспечить перекрытие соединяемых частей минимум 1.5–2 размера voxel.
7. Duplicate → join → Voxel Remesh в `OUTPUT`; SOURCE оставить редактируемым.
8. Smooth умеренно; не стирать кончики, впадины и контактные зоны.
9. При необходимости sculpt локально: Grab для пропорций, Inflate для массы, Smooth только для артефактов.
10. Проверить back/side и negative spaces.
11. Создать low/web version, validate, export GLB.

## Что строить какими частями

| Форма | База |
|---|---|
| голова, шар, сустав, ладонь | ellipsoid |
| корпус, манжета, обувь, мягкий куб | rounded box |
| палец, рука, хвост, провод, рог | Bézier tube с переменным radius |
| органическое соединение | overlap + voxel union |
| тонкий точный фронтальный элемент | contour relief |

## Когда не объединять

Не объединять части, если они должны:

- двигаться отдельно;
- иметь разные прозрачные материалы;
- сохранять жёсткий шов;
- быть заменяемыми вариантами.
