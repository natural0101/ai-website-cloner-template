# Политика активации без помех базовому агенту

Активировать этот модуль, когда запрос содержит одно из следующего:

- объёмная фигура, персонаж, рука, конечность, mascot, sculpt;
- построить объект из примитивов;
- повторить 3D‑иконку/объект по изображению;
- silhouette, contour, mask, relief, 2.5D;
- true 360, turntable, editable GLB сложной формы.

Не активировать для:

- обычного 3D‑текста;
- только материала/цвета готовой геометрии;
- простой сферы, куба или стандартной иконки, покрытой базовым toolkit;
- задач без Blender.

При активации сначала читать только `SKILL.md`, затем ровно один workflow‑файл. Не добавлять все справочники в контекст одновременно.
