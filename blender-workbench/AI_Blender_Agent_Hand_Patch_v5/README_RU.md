# AI Blender Agent — Hand Reconstruction Patch v5

Фокусированное дополнение для стилизованных рук, ладоней, пальцев, манжет и взаимодействия руки с предметом по одному референсу.

## Что исправляет

Патч запрещает два типичных провала:

1. `raster mask → extrusion`, из-за которого рука становится рваной плоской пластиной;
2. `palm ellipsoid + одинаковые tubes`, из-за которого рука выглядит как набор трубок.

Вместо этого агент обязан подготовить парную спецификацию:

- точный видимый 2D-контур;
- семантические landmarks;
- центральные линии пальцев;
- радиусы вдоль пальцев;
- скрытое продолжение под перекрывающим объектом;
- порядок слоёв;
- профиль толщины для 3D.

## Активация

Загружать только для задач с руками, кистями, пальцами, рукавами или органическими конечностями. Не загружать для текста, материалов, света и простых геометрических объектов.
