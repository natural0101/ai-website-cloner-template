# Вставить в prompt агента

Активируй этот режим только для задач с рукой, кистью, пальцами, манжетой или органической конечностью.

## Главный принцип

Не выбирай между «точный 2D» и «настоящий 3D». Создавай обе спецификации одновременно:

1. camera-space target для фронтального совпадения;
2. semantic volume target для правдоподобного объёма.

## До 3D

1. Зафиксируй исходный размер, crop, aspect ratio и ортографическую камеру.
2. Раздели изображение на semantic layers: предмет, видимая часть руки, скрытая часть руки, манжета, фон.
3. Не используй raw pixel contour как финальную кривую.
4. Построй сглаженный Bézier-контур вручную или по малому числу опорных точек.
5. Разметь palm center, wrist axis, thumb base, thumb tip, четыре fingertip, три finger valleys, thumb web и точки входа/выхода из occlusion.
6. Построй centerline для каждого пальца, большого пальца, ладони и запястья.
7. Укажи radius profile вдоль каждой centerline.
8. Нарисуй скрытое продолжение руки под предметом пунктиром.
9. Сохрани `hand_target.json`.
10. Создай `hand_target_board.png`.
11. Проверь JSON валидатором.
12. Покажи board пользователю до финальной геометрии.

## 3D-построение

1. Используй project-owned canonical hand base, если он существует.
2. Создай canonical base один раз с нуля, если его нет.
3. Сохраняй ладонь, пальцы, большой палец, запястье и манжету как отдельные SOURCE-объекты.
4. Подгоняй pose и пропорции по landmarks и centerlines.
5. Вводи пальцы внутрь массы ладони с overlap.
6. Делай пальцы разной длины, кривизны и толщины.
7. Сужай radius к кончикам.
8. Сохраняй negative spaces между пальцами.
9. Создавай OUTPUT-копию перед union/remesh.
10. Выполняй voxel union только после прохождения front silhouette gate.
11. Используй clay material и нейтральный свет до shape approval.
12. Не исправляй форму материалом, roughness, HDRI или тенями.

## Сравнение

1. Рендери filled white mask на black background.
2. Сравнивай с reference mask в исходном разрешении.
3. Используй mask IoU.
4. Используй boundary F1 с допуском 2–3 px.
5. Используй landmark RMSE.
6. Проверяй количество negative spaces и их расположение.
7. Не используй `edge_iou` как единственный критерий.
8. Рендери front, 3/4 и side clay views.
9. Не принимай plate-like volume даже при хорошем front match.

## Запрет самооценки

Не пиши «хорошо», «качественно», «почти готово» или «95%», если gates не пройдены.

Вместо субъективной оценки выводи:

- mask IoU;
- boundary F1;
- landmark RMSE;
- список непройденных gates;
- следующий локальный шаг;
- ссылки на front overlay, side clay render и QA JSON.

## Политика отклонения

Отклони результат и продолжи работу, если выполнено хотя бы одно условие:

- палец не читается отдельно;
- количество пальцев неверно;
- ладонь выглядит плоской пластиной;
- контур рваный;
- raw mask artifacts перенесены в mesh;
- рука и манжета не образуют цельную массу;
- occlusion graph неверен;
- front silhouette прошёл, но side view не имеет объёма;
- SOURCE-геометрия потеряна;
- метрика объявлена без сохранённого overlay.

## Формат каждого отчёта

1. `STAGE`.
2. `FILES`.
3. `METRICS`.
4. `FAILED_GATES`.
5. `NEXT_ACTION`.

Одна итерация исправляет только одну категорию ошибки.
