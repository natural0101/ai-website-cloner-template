# Чеклист визуальной проверки

## Общая проверка

1. Слово читается с первого взгляда.
2. Силуэт соответствует стилю.
3. Толщина букв видна.
4. Bevel есть и не ломает форму.
5. Материал отличается от простого цвета.
6. Свет подчёркивает форму.
7. Камера не искажает буквы.
8. В кадре есть отступ 8–12%.
9. Нет случайных объектов.
10. Сцена экспортируется в GLB.

## Chrome/silver

1. Есть metallic=1.
2. Roughness не выше 0.18 для chrome.
3. Есть чёрно-белые reflection cards.
4. На краях есть яркие highlights.
5. На лицевой поверхности есть контрастные отражения.
6. Если выглядит серым — проблема в окружении, не в цвете.

## Clay/plasticine

1. Metallic=0.
2. Roughness высокий.
3. Края мягкие.
4. Есть слабые неровности поверхности.
5. Тень мягкая.
6. Неровности не портят читаемость.

## Web export

1. Triangle count записан в report.
2. Материалы PBR/glTF-friendly.
3. Origin близко к центру.
4. Scale нормальный.
5. Для chrome на сайте предусмотрено environment/reflection.
