# Схемы

- `scene_graph.schema.json`: части, размеры, representation и spatial/contact relations.
- `stage_state.schema.json`: этапы, попытки, checkpoints и unresolved checklist.
- `example_record.schema.json`: минимальный формат проверенного опыта.

Схемы не заставляют агента загружать весь JSON в контекст. Они задают стабильный machine-readable contract.
