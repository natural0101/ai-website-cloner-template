# Уровни доверия

## Высокое доверие

- MCP подключает агента к инструментам, но не обучает профессии.
- Blender Python API позволяет создавать редактируемые объекты, материалы, свет, камеры и exports.
- High-level tools уменьшают зависимость от хрупкого raw API.
- Render/inspect loop полезнее one-shot generation.
- Geometry, material, composition и lighting нужно проверять раздельно.
- Текущие агенты всё ещё часто ошибаются в API и пространственных соединениях.
- Один маленький reference не содержит истинной скрытой геометрии.

## Среднее доверие

- RAG из качественных Blender examples заметно улучшает код и соответствие. Поддерживается исследованиями, но цифры пока в основном авторские.
- Planner/Actor/Critic и candidate selection обычно повышают результат. Эффект зависит от verifier и бюджета.
- Multi-agent specialization полезна, но оптимальное число агентов неизвестно.

## Низкое доверие

- “Полностью заменяет 3D-художника”.
- “Любой объект за один prompt”.
- “95% exact 360° по одной маленькой картинке”.
- Vendor usage counts без независимой проверки.
- Один YouTube before/after без source file и полного лога.
