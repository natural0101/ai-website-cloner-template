# Python-модули v4

- `stage_orchestrator.py`: stage scope, budgets, checkpoints, bounded memory и structured errors.
- `retrieval_index.py`: локальный BM25-подобный поиск по `examples.jsonl`; только stdlib.
- `security_guard.py`: advisory AST/path preflight. Это **не полноценная sandbox**.

Эти модули работают вне Blender и не требуют установки пакетов.
