# Формат ответа critic

Critic не пишет новый Blender-код. Он возвращает:

1. `stage`;
2. `approved: true/false`;
3. `dominant_mismatch` — один главный дефект;
4. `evidence` — вид/объект/число;
5. `do_not_change` — удачные части;
6. `next_edit` — одно конкретное действие;
7. `acceptance_test` — как проверить исправление.

Запрещены формулировки “сделай красивее”, “улучши всё”, “почти похоже” без измеримого действия.
