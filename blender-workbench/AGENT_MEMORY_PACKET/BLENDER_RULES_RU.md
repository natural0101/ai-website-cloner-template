# Blender Rules For This Project

## Главный принцип

Blender не должен быть "случайным bpy-кодом". Для каждого прохода должен быть режим, этап, артефакт, проверка и честная оценка.

## Для hands/sphere

Референс описывает не просто "руку с шаром". Он задает:

- фронтальный icon crop;
- зеленый шар в центре;
- нижнюю руку как мягкую чашу под шаром;
- верхнюю руку как мягкий обхват сверху;
- широкие округлые пальцы, не анатомические кости;
- отдельные розовые манжеты;
- soft toy/clay материал;
- мягкий свет и чистую белую карточку.

## Как строить руку

Руку нельзя делать как плоскую выдавленную маску.

Правильная конструкция:

- palm ellipsoid / palm cup как главная масса;
- root pad, куда пальцы входят, а не висят отдельно;
- 4 tapered finger capsules, все разной длины, толщины и кривизны;
- отдельный thumb capsule с thenar/web mass;
- wrist как tapered volume;
- cuff как отдельный мягкий цилиндрический объем;
- union/smoothing только после того, как силуэт и контакт читаются.

## Пальцы

Пальцы должны:

- иметь читаемые rounded tips;
- выходить из palm mass, но не исчезать внутри нее;
- быть разными по длине и углу;
- иметь читаемые valleys/negative spaces;
- не выглядеть как одинаковые трубки;
- не образовывать случайный веер.

## Проверки

Минимум перед показом:

- front render;
- 3/4 render;
- side render;
- opaque render с шаром;
- clay render без материала, чтобы форма не пряталась за светом;
- validation report;
- web preview.

## Если результат плохой

Не пытайся "докрасить" плохую форму.

Сначала исправь геометрию:

1. silhouette;
2. proportions;
3. occlusion;
4. contacts;
5. side thickness;
6. material;
7. lighting;
8. export.

## Чего не хватает текущей ветке

Следующему проходу нужно улучшить один дефект:

```text
fingertip readability while preserving compact palm cup
```

То есть пальцы должны стать понятнее, но нижняя рука не должна снова превратиться в широкий веер.
