# Agent Memory Packet

Это переносимая папка памяти для продолжения Blender-задач в новом чате или другим агентом.

Она не является магическим дообучением модели. Это рабочий пакет контекста: что уже сделано, какие ошибки нельзя повторять, какие файлы являются актуальными, как проверять качество и с какого места продолжать.

## Как использовать

1. В новом чате открой проект:

```text
C:\Users\se-20\OneDrive\Рабочий стол\ai-website-cloner-template
```

2. Вставь текст из:

```text
blender-workbench/AGENT_MEMORY_PACKET/PASTE_INTO_NEW_CHAT_RU.md
```

3. Попроси агента сначала прочитать:

```text
blender-workbench/AGENT_MEMORY_PACKET/START_HERE_RU.md
```

4. Агент должен продолжать работу от текущего состояния, а не начинать Blender-сцену заново.

## Что внутри

- `START_HERE_RU.md` - порядок входа в задачу.
- `PASTE_INTO_NEW_CHAT_RU.md` - готовый текст для нового чата.
- `CURRENT_WORK_RU.md` - актуальное состояние проекта и текущий asset.
- `BLENDER_RULES_RU.md` - сжатые правила по Blender/рукам/референсу.
- `ARTIFACTS_INDEX_RU.md` - список важных файлов.
- `NEXT_STEPS_RU.md` - что делать следующим проходом.
- `CHECKLIST_RU.md` - критерии приемки.
- `SESSION_REPORT_2026-06-23_RU.md` - что уже было сделано в этой серии.
