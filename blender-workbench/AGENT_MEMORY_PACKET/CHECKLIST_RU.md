# Acceptance Checklist

## Нельзя говорить "готово", пока нет

- `.blend`
- `.glb`
- front render
- 3/4 render
- side render
- web preview
- validation report
- честная визуальная оценка

## Lower hand checklist

- Нижняя рука держит шар снизу, а не просто находится рядом.
- Шар перекрывает часть ладони корректно.
- Ладонь выглядит объемной чашей.
- Пальцы широкие, мягкие, разной длины.
- 4 кончика пальцев читаются.
- Большой палец не похож на пятый параллельный палец.
- Запястье входит в манжету.
- Манжета отдельная и мягкая, не сливается грязно с рукой.
- Есть side thickness.
- Нет jagged edges.
- Нет случайных зубцов.
- Нет floating parts.

## Web checklist

- `npm run typecheck` проходит.
- Route открывается:

```text
http://127.0.0.1:3000/bottom-hand-part
```

- Browser console без ошибок.
- GLB загружается из `public/models/`.
- Cache-buster обновлен, если файл заменен.

## Communication checklist

Пользователь хочет результат, а не техническую лекцию.

Показывай:

- что изменено;
- где смотреть;
- какие файлы созданы;
- честно: принято/не принято как финал.

Не перекладывай на пользователя оценку landmark board, если он не просит.
